# Discover · versiones para testers

Aquí están los APK de prueba de Discover.

1. Abre [la última versión](https://github.com/Titoraf/Discover-releases/releases/latest).
2. Baja el archivo `.apk`.
3. Ábrelo en el teléfono y toca Instalar.

Si Android pregunta, permite instalar apps de esta fuente.
